AmaderPay কেন ব্যবহার করবেন?

আমাদের স্মার্ট SMS গেটওয়ে ব্যবহারের সুবিধাগুলো নিচে দেখুন

ইনস্ট্যান্ট SMS ভেরিফিকেশন

পেমেন্ট সম্পন্ন হওয়ার সাথে সাথেই অ্যান্ড্রয়েড মোবাইল অ্যাপের মাধ্যমে TrxID অটোমেটিক সার্ভারে সিঙ্ক হয়।

Device Key মেকানিজম

আপনার নিজস্ব ইউনিক Device Key দিয়ে আপনার ফোন সার্ভারের সাথে কানেক্ট থাকে, যা ১০০% সিকিউর।

রিয়েল-টাইম Webhook

পেমেন্ট সম্পন্ন হওয়া মাত্রই আপনার সার্ভারে অটোমেটিক Webhook Callback নোটিফিকেশন পৌঁছে যাবে।

সহজ API ইন্টিগ্রেশন

PHP, JavaScript, Python বা যেকোনো ভাষায় মাত্র কয়েক লাইনের কোডে আপনার ওয়েবসাইটে যুক্ত করুন।

মার্চেন্ট ড্যাশবোর্ড

একটি সুসজ্জিত ড্যাশবোর্ড থেকে মোট লেনদেন, দৈনিক ভলিউম এবং API Key নিয়ন্ত্রণ করুন।

Android 14+ সাপোর্টেড

আধুনিক Android ভার্সনে ব্যাকগ্রাউন্ডে নিরবচ্ছিন্নভাবে সার্ভিস চালুর নিশ্চয়তা।

কীভাবে কাজ করে? (Step by Step)

Step 1

অ্যাকাউন্ট খুলুন

মার্চেন্ট পোর্টালে সাইন আপ করে API Key ও Device Key পান।

Step 2

APK ইনস্টল করুন

আমাদের Android অ্যাপটি ফোনে ইনস্টল করে Device Key সেট করুন।

Step 3

API ইন্টিগ্রেট করুন

আপনার ওয়েবসাইটে /checkout/create API দিয়ে পেমেন্ট লিঙ্ক তৈরি করুন।

Step 4

অটো ভেরিফিকেশন

কাস্টমার পেমেন্ট করা মাত্রই SMS রিড করে সার্ভার অটো ভেরিফাই করবে।
