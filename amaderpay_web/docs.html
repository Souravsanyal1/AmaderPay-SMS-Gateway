অথেনটিকেশন (Authentication)

সবগুলো সংরক্ষিত API এন্ডপয়েন্টে রিকোয়েস্ট পাঠানোর সময় HTTP Header এ আপনার নিবন্ধিত x-api-key অন্তর্ভুক্ত রাখতে হবে। আপনার ইউনিক API Key টি পেতে মার্চেন্ট পোর্টালে লগইন করুন।

HTTP Header Format 
x-api-key: ap_live_your_merchant_api_key_here
১
POST /api/v1/checkout/create

পেমেন্ট সেশন তৈরি করুন

আপনার ওয়েবসাইট থেকে কাস্টমারের পেমেন্ট শুরু করার জন্য এই API এন্ডপয়েন্টটি কল করুন। এটি একটি ইউনিক checkout_url রিটার্ন করবে যেখানে কাস্টমার bKash/Nagad পেমেন্ট সম্পন্ন করতে পারবে।

Request

Request Example 
curl -X POST https://amader-pay-sms-gateway.vercel.app/api/v1/checkout/create \
  -H "Content-Type: application/json" \
  -H "x-api-key: ap_live_your_merchant_api_key_here" \
  -d '{
    "amount": 500,
    "customer_name": "Sourav Islam",
    "customer_email": "sourav@example.com",
    "redirect_url": "https://yoursite.com/payment-success"
  }'

GET /api/v1/checkout/verify/:id

পেমেন্ট স্ট্যাটাস ভেরিফাই করুন

সেশন আইডি দিয়ে যেকোনো লেনদেনের রিয়েল-টাইম স্ট্যাটাস, TrxID, পেমেন্ট মেথড (bKash/Nagad) এবং প্রেরকের ফোন নম্বর ভেরিফাই করতে এই এন্ডপয়েন্টটি ব্যবহার করুন।

Request

cURL Request Example 
curl -X GET https://amader-pay-sms-gateway.vercel.app/api/v1/checkout/verify/pay_sess_a1b2c3d4e5

Response 200 OK

EVENT /api/v1/webhook/trigger

রিয়েল-টাইম Webhook Callback

কাস্টমার পেমেন্ট সম্পন্ন করা মাত্রই NexoraPay আপনার কনফিগার করা Webhook URL এ HTTP POST নোটিফিকেশন পাঠাবে। সুরক্ষার জন্য প্রতিটি নোটিফিকেশনে X-AmaderPay-Signature হেডার যুক্ত থাকে।

Webhook Payload Example 
{
  "event": "payment.completed",
  "data": {
    "trx_id": "BKASH987654321",
    "amount": 500,
    "payment_method": "BKASH",
    "sender_phone": "01711223344",
    "status": "COMPLETED",
    "session_id": "pay_sess_a1b2c3d4e5"
  }
}
Reference

HTTP Response Status Codes

Status Code Status Name বিবরণ (Description)
200 / 201 Success রিকোয়েস্ট সফলভাবে সম্পন্ন হয়েছে।
400 Validation Error অনুরোধে প্রয়োজনীয় ফিল্ড (যেমন: amount) অনুপস্থিত।
401 Invalid API Key ভুল বা অনুপস্থিত x-api-key হেডার।
404 Session Not Found প্রদত্ত সেশন আইডি খুঁজে পাওয়া যায়নি।
