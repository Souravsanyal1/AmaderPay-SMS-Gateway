অথেনটিকেশন (Authentication)

সমস্ত সংরক্ষিত API এন্ডপয়েন্টে অনুরোধ পাঠানোর সময় HTTP Header এ আপনার x-api-key পাঠাতে হবে। আপনার অনন্য API Key টি পেতে মার্চেন্ট ড্যাশবোর্ডে লগইন করুন।

HTTP Header 
x-api-key: ap_live_your_merchant_api_key_here
POST /api/v1/checkout/create

১. পেমেন্ট সেশন তৈরি করুন

নতুন পেমেন্ট সেশন তৈরি করে একটি অনন্য checkout_url তৈরি করে। কাস্টমারকে এই ইউআরএল-এ রিডাইরেক্ট করলে সে bKash/Nagad পেমেন্ট করতে পারবে।

Request Body (JSON):

JSON Payload
{
  "amount": 500,
  "customer_name": "Rahim Ahmed",
  "customer_email": "rahim@example.com",
  "redirect_url": "https://amader-pay-sms-gateway.vercel.app/merchant"
}

Response Example (201 Created):

JSON Response
{
  "success": true,
  "message": "Checkout session created successfully",
  "data": {
    "session_id": "pay_sess_a1b2c3d4e5",
    "checkout_url": "https://amader-pay-sms-gateway.vercel.app/checkout?session_id=pay_sess_a1b2c3d4e5",
    "amount": 500,
    "status": "PENDING",
    "created_at": "2026-08-05 12:00:00"
  }
}
GET /api/v1/checkout/verify/:id

২. পেমেন্ট স্ট্যাটাস ভেরিফাই করুন

সেশন আইডি দিয়ে যেকোনো পেমেন্ট ভেরিফাই করতে এই এন্ডপয়েন্ট ব্যবহার করুন।

JSON Response
{
  "success": true,
  "data": {
    "session_id": "pay_sess_a1b2c3d4e5",
    "amount": 500,
    "status": "COMPLETED",
    "trx_id": "BKASH987654321",
    "payment_method": "BKASH",
    "sender_phone": "01711223344"
  }
}
