অথেনটিকেশন (Authentication)

সবগুলো সংরক্ষিত API এন্ডপয়েন্টে রিকোয়েস্ট পাঠানোর সময় HTTP Header এ আপনার নিবন্ধিত x-api-key অন্তর্ভুক্ত রাখতে হবে। আপনার ইউনিক API Key টি পেতে মার্চেন্ট পোর্টালে লগইন করুন।

HTTP Header Format 
x-api-key: ap_live_your_merchant_api_key_here
POST /api/v1/checkout/create

১. পেমেন্ট সেশন তৈরি করুন

আপনার ওয়েবসাইট থেকে কাস্টমারের পেমেন্ট শুরু করার জন্য এই API এন্ডপয়েন্টটি কল করুন। এটি একটি ইউনিক checkout_url রিটার্ন করবে যেখানে কাস্টমার bKash/Nagad পেমেন্ট সম্পন্ন করতে পারবে।

cURL Request Example
curl -X POST https://amader-pay-sms-gateway.vercel.app/api/v1/checkout/create \
  -H "Content-Type: application/json" \
  -H "x-api-key: ap_live_your_merchant_api_key_here" \
  -d '{
    "amount": 500,
    "customer_name": "Sourav Islam",
    "customer_email": "sourav@example.com",
    "redirect_url": "https://yoursite.com/payment-success"
  }'
PHP Request Example
<?php
$apiKey = 'ap_live_your_merchant_api_key_here';
$data = [
    'amount' => 500,
    'customer_name' => 'Sourav Islam',
    'customer_email' => 'sourav@example.com',
    'redirect_url' => 'https://yoursite.com/payment-success'
];

$ch = curl_init('https://amader-pay-sms-gateway.vercel.app/api/v1/checkout/create');
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'Content-Type: application/json',
    'x-api-key: ' . $apiKey
]);

$response = json_decode(curl_exec($ch), true);
curl_close($ch);

if ($response['success']) {
    header('Location: ' . $response['data']['checkout_url']);
    exit;
}
Node.js / Axios Example
const axios = require('axios');

async function createCheckoutSession() {
  try {
    const res = await axios.post('https://amader-pay-sms-gateway.vercel.app/api/v1/checkout/create', {
      amount: 500,
      customer_name: 'Sourav Islam',
      customer_email: 'sourav@example.com',
      redirect_url: 'https://yoursite.com/payment-success'
    }, {
      headers: { 'x-api-key': 'ap_live_your_merchant_api_key_here' }
    });

    console.log('Checkout URL:', res.data.data.checkout_url);
  } catch (err) {
    console.error('Checkout error:', err.response.data);
  }
}

Flutter / Dart (http package)
// pubspec.yaml dependencies তে যোগ করুন:
// http: ^1.2.0

import 'dart:convert';
import 'package:http/http.dart' as http;

// ── Checkout Create ──
Future<String> createCheckoutSession() async {
  const apiKey = 'ap_live_your_merchant_api_key_here';

  final response = await http.post(
    Uri.parse(
      'https://amader-pay-sms-gateway.vercel.app/api/v1/checkout/create',
    ),
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': apiKey,
    },
    body: jsonEncode({
      'amount': 500,
      'customer_name': 'Sourav Islam',
      'customer_email': 'sourav@example.com',
      'redirect_url': 'https://yoursite.com/payment-success',
    }),
  );

  if (response.statusCode == 201) {
    final data = jsonDecode(response.body) as Map<String, dynamic>;
    final checkoutUrl = data['data']['checkout_url'] as String;
    print('✅ Checkout URL: \$checkoutUrl');
    return checkoutUrl;
  } else {
    throw Exception('❌ Checkout failed: \${response.body}');
  }
}

// ── Checkout Verify ──
Future<Map<String, dynamic>> verifyPayment(String sessionId) async {
  final response = await http.get(
    Uri.parse(
      'https://amader-pay-sms-gateway.vercel.app/api/v1/checkout/verify/\$sessionId',
    ),
  );

  final data = jsonDecode(response.body) as Map<String, dynamic>;
  if (data['success'] == true) {
    print('💳 Status: \${data['data']['status']}');
    print('🔖 TrxID:  \${data['data']['trx_id']}');
  }
  return data;
}

৩. রিয়েল-টাইম Webhook Callback

কাস্টমার পেমেন্ট সম্পন্ন করা মাত্রই AmaderPay আপনার কনফিগার করা Webhook URL এ HTTP POST নোটিফিকেশন পাঠাবে। সুরক্ষার জন্য প্রতিটি নোটিফিকেশনে X-AmaderPay-Signature হেডার যুক্ত থাকে।

HTTP Response Status Codes

Status Code Status Name বিবরণ (Description)
200 / 201 Success রিকোয়েস্ট সফলভাবে সম্পন্ন হয়েছে।
400 Bad Request Validation Error অনুরোধে প্রয়োজনীয় ফিল্ড (যেমন: amount) অনুপস্থিত।
401 Unauthorized Invalid API Key ভুল বা অনুপস্থিত x-api-key হেডার।
404 Not Found Session Not Found প্রদত্ত সেশন আইডি খুঁজে পাওয়া যায়নি।
